# 美术方向与制作规范

## 2026-09-15用户反馈后的优先规则

用户指出首版规整SVG与《信任的进化》不匹配。现优先查询和复用官方原图、图集与三态按钮；下文“SVG／HTML”只继续用于数据、语义和显示容器，不再据此批量画一套线性插画。首版19个自绘SVG退出使用。详细变更与剩余缺口见[首批制作修订](06_首批制作与原作素材修订.md)。已有原图的颜色、笔触和比例为当前视觉依据，下面2026-09-14候选色值不强制覆盖原素材。

## 方向：简笔手绘的关系实验室

延续现有白底、深色轮廓、少量强调色和大留白。原作人物和机器可作首批原型候选，新的关系图、对象与控件采用代码原生SVG／HTML。此轮不使用生成式图片：大多数资源需要精确计数、响应式布局和可逆状态，位图不适合作为真值。

画面主角是“两位劳动者—机器—产品托盘”，不是工业城市全景。章节更替以局部对象出现和镜头范围改变体现，不制作35张整屏插画。现实镜头另有来源身份；两位工人不会突然变成平台司机、患者或中国保障个案。

## 风格变量（制作目标，尚未写入页面CSS）

- 纸面：#ffffff；主轮廓／正文：#222222；辅助文字：#595959；弱分隔：#d3d3d3。
- 强调沿用项目候选：蓝#285fbd、赭红#cf3a2b、淡黄#ffdc63；不把蓝红分配给国家制度或善恶。淡黄只作底色，不作白底小文字。
- SVG轮廓建议2–3 CSS px、圆端点，允许轻微不规则但不得摇晃数字、精确刻度和连接端点；缩放后检查线宽。
- 中文继续使用项目系统字体栈Microsoft YaHei／PingFang SC／system-ui，不新增未核许可字体，不将正文和数字烘焙进图片。
- 图标建议48×48设计网格，复杂节点96×72，标签另排；实际布局不是按整张画布等比缩到手机。

## 人物规则

原人物条带为2400×325，8格，每格300×325。已有页面用0号与2号作为两位劳动者；可继续保持视觉认知，姓名与身份外置。所有者的身份来自产权线，不来自黑帽、坏笑或体型。不要将原作策略类型映射成劳动者／资本家的道德性格。

本轮只需静止、选中、焦点、历史对照的展示状态。后续移动由组件位置变化完成，不先制作复杂人物动画。统计群体另用中性轮廓和分组计数，不将同一人物反复排满屏代表真实个体。

## 原图与图集

三张已核对本地来源记录的候选图片：
- 人物：8格300×325；索引0–7，越界不得截到相邻人物。
- 机器：2048×2048图集中有效帧x10、y10、w1398、h498；大量透明区不能当作构图留白直接缩放。
- 金币：128×128图集中有效帧x10、y10、w102、h102。

帧坐标来自本地图集与现有CSS检查；两个JSON本身尚无固定源文件哈希登记。实现应明示裁切框并做越界验证，不沿用魔法百分比猜裁切。原PNG不改写，派生裁切如未来需要另存并记parent hash。当前只是登记，不导出新裁片。

## 状态而非35张图

所有交互对象至少设计：默认、可操作、选中／预览、已提交、不可用及原因、键盘焦点。支持撤销的对象另有基准／历史态。未知、示范、失效是记录身份，不是一种灰掉即删除的效果。

参考动画时间：即时反馈100–180ms；对象移位180–300ms；跨场景切换最多400ms。它们只是待试玩目标，不阻塞模型结算或跳过操作；关闭动画时显示同样的前后帧。无自动播放音频，无闪烁报警或强制慢镜头。

## 语义必须由形状和标签共同表达

| 语义 | 视觉规则 |
| --- | --- |
| 协作／产权／控制 | 分别有端点和线型，不只换颜色；带关系名 |
| 预测／实际 | 空心／实心标记，文字标预测与实际 |
| 产品／货币／小时／人次 | 方块／硬币／时间尺／群体轮廓；每个数有单位 |
| 债务／现金／资产 | 不同账目字段；不能画成同一钱包 |
| 真实证据／教学模型 | 固定H/T/E/D身份条，并可看地区与时间 |
| 示例／亲历／过期 | 明确标注，不仅用透明度区别 |
| 正常流动／支付延迟 | 金额和是否付款可读，断线不代表自动破产 |

## 手机与读屏

320px宽和200%文字放大需重排；至少44px目标区，不把整张宽屏画缩成小字。默认最多3个焦点，其他对象留位置但降干扰。鼠标悬停不是唯一提示；拖动提供点选和键盘路径。装饰图aria-hidden，具有信息的图提供名称和可读数字，长图表附表格。

这些是验收规格，尚未测得颜色对比全部通过、手机适配或读屏表现完成。

## 不采购／不生成清单

无需逼真工厂背景、虚构患者照片、银行倒塌爆炸、国家善恶头像、万能AI脑、装饰性论文截图、三维金币雨、真人历史肖像合集、第三方logo或图内中文段落。缺研究截图时优先真实文字来源卡，而非生成看似真实的论文封面。

有明确用途的位图插画如后续确需生产，再逐张确认构图、透明背景、状态和统一风格；不要以生成一张整屏截图代替可交互资源。

## 制作出口

每类资源的默认态、至少一个对照态、空／未知／错误态、手机与减少动态示例都要可检查；对应数据由模型供给而非素材携带固定答案。验收后再将productionStatus改为已制作并填实际路径。真实资料版本、权利与字形清晰度单独核验，不能通过美术验收替代。
