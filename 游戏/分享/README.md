## 设计与扫码检查

分享卡沿用游戏的文楷字体、灰色线条、米白底和少量金币黄。新增装饰插画由内置 imagegen 工具生成，只用于分享卡；完整提示词、文件哈希和制作方式见[制作与来源](制作与来源.json)。游戏中原有素材的署名和许可见[素材致谢](../CREDITS.md)。

二维码由代码独立生成，保留四模块留白，装饰不进入码区。二维码图案由确定性矩阵产生，AI 仅生成上方的插画。

zxing-cpp 软件解码共 7 项通过：两种二维码各检查原图及 50% 缩小图；分享卡检查 1080px、540px 和 324px 宽度。全部解码为上述试玩地址，记录见[扫码校验](扫码校验.json)。未进行实体手机或微信扫一扫实测。

## 继续调整分享卡

版面源文件是[分享卡 HTML](分享卡.html)，引用本目录插画、SVG 二维码和游戏已有的 OFL 字体。修改版面后，在游戏目录运行：

```sh
node scripts/render-share-card.mjs
```

脚本需可用的 Playwright 与 Edge，也可通过 `PROLOGUE_PLAYWRIGHT_MODULES` 和 `PROLOGUE_BROWSER_EXECUTABLE` 指定本机路径。它会重新导出分享卡和配色二维码；更换网址时，须同时重新生成二维码矩阵并再次解码检查。
