# 对决续玩逻辑优化 · 2026-10-17

第二幕现在记住已经完成的开局说明，并在经营动画开始前保存这一回合的结算结果。刷新、暂时离开章节和动画中断后，都能回到已经结算的账单。

## 玩家能感受到的变化

- 首次进入仍需读完五页开局说明。读完后，即使还没经营第一天就刷新，也不会被迫再读一遍；工具栏仍可随时打开说明，主动打开的说明可以直接关闭。
- 选择经营策略后，先保存本回合结果，再播放人物和交易动画。动画期间刷新或返回首页，重新进入时会显示这次的账单，购机付款和明日交付安排也会保留。
- 取消交易动画会正常收束到账单，经营按钮能恢复。撤回仍按原规则恢复上一回合的实际账目。
- “重开”与“重打这一场”继续重置相应账目，但熟悉规则的玩家无需重新读开局说明。接受旧版规则升级时，仍会展示新版说明，并保留旧账。

旧存档没有阅读标记也能恢复；已经经营过的旧存档按已读处理。阅读标记只控制说明是否自动弹出，不能完成经营回合、改变账户或解锁未完成的结局。

43 项相关单元测试通过，范围包括阅读标记、旧存档、账目校验、撤回、第一幕衔接、章节浏览、设备投资及三阶段经营模型。其中包含 100 条完整经营路径的账目守恒与回放检查。

[续玩浏览器检查脚本](../scripts/test-battle-resume.mjs)通过真实界面操作，覆盖 390×667 和 1280×900 两种尺寸：首次说明不可跳过、第一天开门前刷新、主动关闭说明、动画中刷新、撤回、取消动画、购机动画期间离开、重开，以及完整打完三场并进入第三幕。脚本不注入游戏状态。

原有常用流程另行检查第一幕、第一回合、返回首页、各章导航、刷新、动效偏好切换和真实字体提供者。完整 47,449 个字符映射及24个联网字体分片均已核对。

本轮使用仓库源码重新构建离线成品，联网版由同一成品派生。源码、离线包、线上资源均保留原完整字体；已有试玩地址与二维码继续使用。

浏览器自动化使用本机 Edge 和模拟视口，未进行实体手机触屏实测。上一轮加载速度数据仍属于上一轮测量，本轮未重新开展性能对照。
