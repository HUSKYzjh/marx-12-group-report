# 第一场：恒定的客流数 · 收益挑战

第一场的目标改为在恒定客流下尽量多赚。开场仍为五页，第一页点明“每天12位顾客，三天怎样赚得最多”；经营面板持续显示目标和本局收益。

每次结算根据玩家实际选择给一句追问。例如，提价后问“少卖了吗？”，降价后问“多卖了吗？再看看每个少收了多少”，换炉后问“还剩几天回本？”。玩家自行比较售价、销量和开销，不指定必须点击的策略。

三天结束后对照本次收益、三天照常营业的收益和个人纪录。未到最高收益时鼓励重试，到达本局上限后明确反馈；可以自由进入下一场。纪录在重玩、刷新和进入下一场后保留，较低的新成绩不会覆盖较高纪录。

## 计分与逻辑

本局以“三天资金净增加”计分，设备款和老板生活费也计入流出。它不是完整净利润：模型未估算设备余值、折旧及期末库存价值。此口径可在账单和本局规则中查看。

当前规则有305条合法三天策略路径。穷举验证最高资金净增为51枚；一种达到上限的路径是提价、提价、照常营业，三天售价为4、5、5，每天各卖6个，收入合计84，资金由36变为87。三天照常营业同样每天卖6个，收入54，资金由36变为57，净增21。玩家可以由此比较“多卖”与“同样销量多回款”。最高分数和最优路径不会在开始时直接展示。

这个结果依赖本局条件：全街每天12位买家，对手固定产量和售价，买家没有单独设置保留价格，售价上限为5。此处的最优路径不能直接作为真实市场的涨价规律。三天内回款最高也不等于长期投资回报最高。下一场继续追问客流变化后原策略是否仍有效。
