# 流程与速度优化 · 2026-10-17

本次优化从打开页面、开始第一幕、返回首页、切换章节到刷新续玩的常用流程。故事与经济规则保持原有实现；改动集中在加载、装饰布局和界面切换。

## 实际变化

首页原先在初始化时计算两次布局，返回时也会重新计算。现在首次只计算一次，返回同尺寸首页复用已有布局，尺寸变化时再重新排列。初始候选搜索从500次调整为96次。装饰动画每帧的计算量受限，切换时暂停装饰更新，避免慢帧反复追赶；擦屏按实际时间推进，正常动效约360ms，可随减少动态效果偏好即时结束。

联网版将原20.5 MB单文件拆为可缓存脚本、样式与图片。页面入口约1.1 KB，正文资源另外加载，首次总传输量仍以浏览器实际记录为准。资源名包含内容哈希；更新时先上传资源，再更新首页，已有二维码与存档键保持一致。

原完整字库约10.9 MB。联网版本把当前游戏所需字符放在约416 KB的首批字库，其余字形按需加载。24个分片的实际字符映射逐一读取，合计47,449个，与原字库完全对应，没有重叠或缺失。原完整字库与单文件离线版继续保留；主舞台和第二幕均检查了真实字体提供者，以及首批字库外的生僻字。

## 后续构建与发布

修改源码后先生成离线版，再生成联网版：

```sh
npm run build:offline
npm run build:hosted
python scripts/verify-hosted.py
```

联网构建需要 Python 的 `fontTools`、Brotli；本次使用 fontTools 4.66.1。`GAME_PYTHON`、`FONT_TOOLS_MODULES` 可指定已有运行环境。字体分片和解码缓存保存在忽略的构建目录中；来源字体不变时可复用。可通过 `GAME_FONT_TTF` 指定原始TTF来加快首次准备，程序会核对来源SHA256。

上传 `build/hosted/` 整个目录到站点根目录，首页最后上传，并保留备份与一致性校验：

```sh
tcb hosting deploy ./build/hosted -e zjh-d0ginayd0c9cbf350 --verify --safe --entry index.html
```

没有使用删除远端其他文件的选项。新构建使用新的内容哈希地址，旧资源可供旧页面继续访问。单文件离线版仍直接打开 `offline/技术红利去了哪里.html`。
