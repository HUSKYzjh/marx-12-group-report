# 公共职务角色与选举制度设计

2026-10-01补充，设计稿，尚未实现。按最新范围，政府角色只讨论资本主义国家中的行政职责与选举约束，以美国联邦众议员为具体选举镜头，不在该角色体现中国体制。中国与资本主义国家的区别留在共同结尾C03。保留个人／企业双入口，公职内部两种岗位不增加顶层入口或强制游玩长度。

这不是竞选获胜攻略，也不建立“花钱买票”的结果公式。作品研究的是技术、积累、分配与政治决策的联系：一人一票的制度规则不等于各群体拥有相同的组织、传播和接触决策者的资源；资源差异也不能直接推出某次投票或政策的必然结果。

## 先分清职位 再展示约束

原个人角色卡“政府工作人员”扩为“政府与公共职务人员”，内部提供行政经办人员与美国联邦众议员两种岗位镜头。民选议员与行政人员不是同一种职务，不能一律叫政府雇员。行政执行模板限定资本主义国家情景，实际政策须注明国家与时期。

| 岗位镜头 | 产生与责任关系 | 玩家操作焦点 | 不能赋予的权力 |
| --- | --- | --- | --- |
| 行政经办人员 | 虚构教学岗位，岗位来源与主管职责明示；本人不参加该场景的公职竞选。实际政策须注明制度背景 | 核对资料、追踪程序和支付、指出执行困难；看政策制定者与服务对象的两端 | 不能直接立法、决定央行政策或全国救助；选举结果也不直接等于本人被解聘 |
| 美国联邦众议员 | 民选立法岗位；众议院成员每两年由人民选举。职责及竞选规则限定为美国联邦层级，不外推到各国或各州所有职务 | 对照选区诉求、竞选资源、任期与长期技术后果；表达议案或表决立场，再查看制度程序 | 不是总统、部长、地方行政首长或央行；个人立场不能自动变成法律、支出或执行结果 |

美国产生方式依据[美国宪法第一条第二款](https://www.archives.gov/founding-docs/constitution-transcript)。任期数字是制度事实，不是模型中的收益参数。原中国职务设计取消，相关已核法律来源保留为共同研究资料，不再生成政府角色的中国制度节点。

## 美国镜头 怎样让选举进入游玩

围绕同一项技术应用的就业、收入与服务后果，加入三个小场景，每次只显示一层关系，不额外弹三篇文章。

第一场“谁在门外，谁能进来”：显示劳动者、经营者及公共服务使用者的虚构诉求卡，比较选民身份、表达渠道与会见资源。民意不是一个统一喜好，也不让所有企业或劳动者自动支持同一政策。玩家可以选择先核对哪份主张，结果揭示它的证据与遗漏，不输出对真实选民的说服方法。

第二场“票与钱不是同一条线”：选票连到产生职位的关系；候选人竞选账户、独立支出组织和公共预算分别显示。Super PAC可以接受个人、企业、工会等来源的无限额捐款以支持独立政治活动，但其资金不能作为直接、实物或协调传播形式的捐助交给联邦候选人或委员会。这里沿用[FEC的Super PAC说明](https://www.fec.gov/help-candidates-and-committees/filing-pac-reports/registering-super-pac/)，不处理各类主体的全部法律规则、具体金额上限或政党协调支出的近期争议。不能把企业资金直接拖入议员公共预算，也不能把Super PAC当候选人的钱包。

第三场“选举到了，技术后果到了吗”：把两年选举节点与培训、收入和风险的后续观察并排。玩家区分“本期看得见”“需要后续跟踪”“未知”；长期结果可以重要，但短期选举与长期成效之间的张力属于条件性分析，不设所有民选者必然短视的定律。M3能力池中的期仍是教学期，不能自动改为真实年。

已有实证可支撑一个较窄环节：Kalla与Broockman的[随机现场实验](https://onlinelibrary.wiley.com/doi/abs/10.1111/ajps.12180)向191个美国国会办公室安排会见请求，随机改变是否告知来访者有竞选捐赠者身份，发现披露该身份提高了与高级决策者会面的机会。论文2015年在线发表、2016年卷期出版。这识别的是身份信息对接触机会的影响，不是随机分配捐款，也不证明可以买下选票、法案或整届政府。本项目未独立复现其数据。

政策环节另给一条程序线：个人议员的立场 → 集体审议与两院通过 → 总统依宪法处理 → 行政执行。它是简化制度镜头，不伪造议案通过率；议员不能跳过其他机关直接执行救助。依据宪法第一条第七款，实际程序还有具体规则和例外，未纳入的细节标范围限制。

## 八节点内的替换 不增加新主线

公共职务角色保留8个专属节点加C01—C04共同结尾。行政人员沿用V8执行模板，06节点只用美国政策证据P20，P29不再进入角色段；美国众议员按下表替换，前六节点不正式引入AI。C03进入角色已结束的研究视图，不提供中国职务扮演。

| 节点 | 美国众议员镜头 |
| --- | --- |
| O01 | 选民与职位产生，立法／行政分开；R21 |
| O02 | 诉求与接触渠道；虚构案例＋R23 |
| O03 | 产品、收入与岗位指标，承诺不等于结果；P02/P09/P10 |
| O04 | 任期节点与长期培养结果的条件对照；M3＋R21 |
| O05 | 集体立法和预算权限，独立资源对照；R21＋P25 |
| O06 | 危机干预对象与本岗位权限；P20，历史与角色分开 |
| O07 | 数字规则与技术权限；P21/P22，不新增选举微定向模型 |
| O08 | 政策成本、实际结果与下一轮问责；P25＋条件分析 |

每个节点只保留一个主操作。选举是解释激励和问责的制度条件，不是另加八轮竞选小游戏。离任、落选或提出不同政策立场均不作为失败通关；资料和结论仍可访问。没有可信投票模型时，选举结果显示未知，不借动画暗示确定胜负。

## 与科技和基本矛盾的回扣

新增的是一条待检验机制：经济资源集中可能形成不均等的组织、传播和接触决策者能力；这些能力可能影响议程、政策约束和分配，从而反馈技术红利与风险承担。选举、劳动组织、监督和公共参与也可能制约这种影响。这些联系不能仅凭法律条文或上述一项会见实验全部证实。

马克思主义基本矛盾仍是生产社会化与生产资料资本主义私人占有的矛盾。政治资源与政策选择是分析其具体表现和调整的重要层面，不改名为“选民与捐款者的矛盾”。资本主义国家政府不因有选举就脱离其社会经济关系；也不能因此抹去选举、组织和改革的真实作用。中国国家制度及具体治理问题沿原独立轨道分析。

## 关系标识 状态和验收

沿用协作、产权、控制、付款标识；选举产生与监督采用有文字标签的独立关系，不能冒充产权或付款。竞选账户、独立支出组织、国库／公共预算互不串账；任期时间线和经济实验时间线分开。

新增officeType、selectionRule、accountabilityTarget、termReference、politicalResourceChannel、policyStage与electionOutcome。officeType仅为administrative／us_house，二者routeId均为individual。electionOutcome默认unknown，无自动由资金或民意标签计算的胜率。换岗位重建权限与制度背景，不能沿用前一岗位的授权、任期或筹款规则；旧中国职务设计记录迁移到角色选择页，不自动转成美国角色或沿用权限。

专项验收：行政人员没有本人的竞选任务；众议员不能直接签发行政救助；角色段无中国制度分支或P29节点；Super PAC资金不转入候选人或公共预算；票、钱、会见与政策结果分别标识；任期不改M3单位；选举未知仍可结束；各岗位的前六节点不正式引入AI。幕间与结尾历史对照另按[美学方案](15_幕间美学与技术历史对照.md)执行。键盘、手机和真人理解均待实施。

角色事实来源为[证据索引R21、R23](03_证据与研究接入.md)，R22仅留作共同研究资料。本轮只做定向核验与设计补充，不保证覆盖所有国家选举、当前全部竞选法规或政治影响研究；没有修改运行页面，也没有新增真实选民画像、宣传投放或政治人格评分。
