# 先决定讨论内容：议题、论证与反例

版本V3。以下是内容选题合同；不是结论正确性的打分题。

V8[多角色编排](13_多角色与公共治理流程.md)将政府工作人员放入个人线。个人处境、企业经营、政府机构与国家制度属于不同分析层级；角色操作不代替国家性质判断。以下议题仍保留完整范围，不因某角色未亲历而改写事实。

2026-10-01编排补充：[双入口流程](12_个人与企业双入口流程.md)让个人与企业从不同处境进入同一论证。下面13组议题继续作为完整内容范围，不要求每个入口逐一走完35幕；结构根源、危机分层、国家制度区别与条件结论仍进入两路共享主线。

## 为什么不能只讲分蛋糕

旧流程能够说明“生产增加不自动加薪”，却不足以回答技术选择、劳动再生产、社会协调、知识控制、生态外部性和国家制度。新增内容必须补齐这些不同层级的因果连接，而不是把“不自动”换词重复35次。

## 七条核心论证链及证据责任

1. 技术能力 → 观察范围 → 实际工作流 → 收益实现 → 分配：P02、P03、P06；AI实证在P32核验。不能从实验室能力直接跳到家庭福利。
2. 局部提速 → 完整任务包 → 空档安排 → 岗位与训练 → 未来能力：P06—P08。跨期命题是待检验机制，不预言一代人必然失去能力。
3. 各厂投资生产 → 竞争争单 → 有支付能力的需求 → 库存与调整：P10—P15。需求示意不是完整宏观周期模型。
4. 广泛协作 → 关键入口与知识控制 → 租费、进入退出与后续创新：P21—P23。必须有实际权利和合同证据，不能只看企业市值。
5. 技术减负 → 扩张效应 → 总量与跨主体责任：P24、P25、P29。数量恒等式、空间分布与因果证据分别陈述。
6. 局部待遇改善 → 可执行参与 → 占有关系 → 国家制度与发展目标：P26—P30。不能把社会所有权化约为几个图标或工资分成比例。

7. 结构根源 → 特定积累与实现困难 → 信用脆弱性 → 冲击与传染 → 有代价的调整：P16—P20。根源不是定时器；机制与触发因素不同，不能跳过历史调查。

## 关键观点如何随着历史推进

P31不是罗列年代：工业革命先提出机器与劳动命运；马克思推进到机器的资本主义应用；大工业和垄断研究讨论组织与集中；战后增长、劳动组织与福利使真实调整成为必须解释的事实；平台／AI／开放知识把控制和协作移到数据与基础设施；社会主义中国发展生产力及制度完善须单列脉络。每一站都问“当时观察到什么、用了什么解释、今天保留和修正什么”。

## 不用作主线结论的说法

- 技术必然造成失业，或技术必然使每个人受益。
- 工资上升说明基本矛盾已消失，或矛盾存在说明改善都是假的。
- 两厂利润增加就是社会更好；政府协调就是社会主义。
- 开源必然消除控制，专利必然阻碍全部创新。
- 中国案例与美国／德国案例数值相减就是国家制度效应。
- 一张利润曲线、一份法律、一段个体经历就证明完整哲学命题。

## 延伸内容及取舍

绝对、相对与超额剩余价值的严格定义放P04解释层；不直接用会计利润去估计剩余价值率。信用金融已进入P17、P19的预算与资产负债放大镜，但不建全口径金融宏观模型；战争和国际货币体系仍只列为可能外部条件。完整的跨国制度因果评估、临床建议、投资建议不属于作品功能。

这一取舍不删除有关问题，而是给出讨论边界：主线必须解释与核心问题最接近的七条链；没有模型或证据的远端因果不靠增加文字伪装已经解决。

## 每页新增信息的最低标准

在该页的“要讨论什么”中写出：继承哪项认识、新增哪项关系、哪一种简单说法被修正。若仅把前页结论换个句子，合并或改成真正的新对照。页面总量只是安排，不是质量指标。

危机根源、具体积累与实现机制、触发因素、放大渠道、调整与恢复五层分开。新增[危机阶段深化](06_危机阶段深化.md)约束三类反馈关系的证据身份；P19支付链只证明假设条件下可发生的传导，不估计宏观危机强度。P20应区分宏观恢复、家庭恢复、损失分担，不把某次衰退结束视作所有矛盾消失。
