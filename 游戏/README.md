# 饥馑的盛宴

围绕“科技与资本主义基本矛盾”制作的教学页游。这里提交当前版本的源码、素材和离线成品，供组员试玩、审阅与继续修改。游戏中的经济过程是有设定条件的教学模型。

## 离线试玩

1. 打开[离线试玩包](饥馑的盛宴_离线试玩.zip)，点击 GitHub 文件页的下载按钮。
2. 解压后，用 Edge、Chrome 或其他现代浏览器打开 `饥馑的盛宴.html`。
3. 无需安装依赖或联网。游戏进度保存在当前浏览器中；换浏览器或移动文件后，可能需要重新开始。

也可下载[单文件 HTML](offline/技术红利去了哪里.html)。GitHub 文件页面显示源码，需下载到本机后打开。本次交付提供离线文件。

建议先试玩第一幕，再进入两店对战与六店沙盒，记录难懂的规则、操作反馈和可以增加幽默感的地方。组内资料与审阅要求见[阅读与审阅安排](../协作/阅读与审阅材料/README.md)。

## 继续开发

需要 Node.js 22.13.0 或更新版本。在本目录执行：

```sh
npm ci
npm run dev
```

生成独立离线版：

```sh
npm run build:offline
```

输出为 `build/index.html` 和 `offline/技术红利去了哪里.html`。重新打包试玩 ZIP 时，须同步替换其中的 HTML。

生成联网托管版（需要 Python、fontTools 及 Brotli）：

```sh
npm run build:offline
npm run build:hosted
```

联网发布请上传 `build/hosted/` 整个目录，其中包含页面、可缓存脚本、图片和字体分片。全部47,449个字形映射保留；原完整字库与离线版继续保留。`GAME_PYTHON` 可指定 Python，`FONT_TOOLS_MODULES` 可指定本地 fontTools 目录。首次准备字体后，后续构建可复用缓存。部署、测量与验证见[流程与速度优化记录](docs/流程与速度优化-20261017.md)。

运行单元测试：

```sh
npm test
```

测试前会自动生成对决嵌入页和四份可复算分析文件；这些缓存不需要从其他电脑复制。

`app/`、`components/`、`lib/` 和 `data/` 保存游戏实现与内容；`public/`、`vendor/` 保存素材和改编所需资源；`scripts/`、`tests/` 保存构建与检查工具。依赖、缓存及本机部署配置不随目录提交。

详细版本说明见[开发与版本说明](开发与版本说明.md)。素材出处、改编说明与许可证见[CREDITS](CREDITS.md)及其引用文件；继续使用素材时请一并保留。
