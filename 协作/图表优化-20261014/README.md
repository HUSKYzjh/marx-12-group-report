# 数据图表可读性修订

本次调整第9、10、11、21、24、25、26页，共9张原生PowerPoint图表。主题、页序、论证及统计口径沿用当前版本。源码以`00e37fd`为基线，构建编号为`charts-d9`。

这是内容修改，供组内通过PR审阅；`成品/`继续对应最近一次正式发布。完整36页候选PPT已在本机构建，合并后由整合负责人统一执行正式交付。

## 页面变化

| 页码 | 变化 | 保留的解释条件 |
| --- | --- | --- |
| 9 投资 | 关键年份数值直接贴近曲线，补齐2024刻度；保留危机年份与跨期机制 | 不变价全社会固定资本形成；累计降幅与同比降幅分别标明 |
| 10 消费 | 两张小图改为并排大图，标出偿债峰值、消费谷值与末值；收入路径移至底部 | 同一季度范围，独立纵轴；PCE为指数，偿债为收入占比 |
| 11 出口 | 曲线标注危机低点与末值；顺差、逆差按方向配色并显示正负号 | 差额/GDP的各国分母不同，比例不能直接相加 |
| 21 能源成本 | 改为横向成对条形，六个成本读数贴在条形末端 | 2010与2024端点比较；LCOE不等于居民电价 |
| 24 客服提效 | 两组使用不同颜色，标签写清15%和约30% | 子群体包含在总体中，不能相加；不是就业减少比例 |
| 25 数据中心 | 估计值用实心柱，预测用浅色空心柱；标明预测约为估计的两倍 | 2025为估计、2030为预测，均包含非AI负荷 |
| 26 工时 | 四个读数直接标注，增加需求增长25%的持平参考线 | 效率提高25%的条件模型，不是现实就业预测 |
